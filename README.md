    <h2 id="project-overview">Project Overview</h2>
    <p>The Caton project is designed to provide a dynamic and user-friendly dashboard application. It includes features such as navigation, data visualization, and animations for enhanced interactivity. The application leverages Material-UI (MUI) for styling and responsiveness, ensuring a polished and professional look.</p>
<div>
    <h2 id="technologies-used">Technologies Used</h2>
    <ul>
        <li><strong>React</strong>: Frontend library for building user interfaces.</li>
        <li><strong>Next.js</strong>: Framework for server-rendered React applications.</li>
        <li><strong>Material-UI (MUI)</strong>: Component library for creating responsive and modern UI.</li>
        <li><strong>JavaScript (JSX)</strong>: For building components and implementing logic.</li>
        <li><strong>CSS/SCSS</strong>: For custom styling.</li>
        <li><strong>JSON</strong>: For managing component data.</li>
        <li><strong>React Router</strong>: For navigation and routing.</li>
        <li><strong>Framer Motion</strong>: For implementing animations.</li>
    </ul>
<div>
    <h2 id="features">Features</h2>
    <ul>
        <li><strong>Responsive Design</strong>: Fully adaptable layout for mobile, tablet, and desktop.</li>
        <li><strong>Navigation Bar</strong>: Interactive navbar with smooth transitions.</li>
        <li><strong>Animations</strong>: Fade-in and fade-out effects for pages and buttons.</li>
        <li><strong>Dynamic Components</strong>: Components like Leaderboard, Recommended Courses, and Doctor Profile, powered by JSON data.</li>
        <li><strong>Separation of Concerns</strong>: JSON files for data management, enhancing scalability and maintainability.</li>
    </ul>

    <h2 id="usage">Usage</h2>
    <h3>Running the Project</h3>
    <p>Use the <code>npm start</code> command to start the development server. Navigate through the application using the navbar or provided buttons.</p>
<div>
    <h3>Adding New Components</h3>
    <ol>
        <li>Create the component file in the <code>components/</code> folder.</li>
        <li>Add the corresponding JSON data in the <code>constants/</code> folder.</li>
        <li>Update the parent component to pass the data as props.</li>
    </ol>
